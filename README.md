# My Video Processing Process

Over the years I have designed, developed, and refined my process for taking the media off of my DVDs and Blu-rays so I can host the content on my private media server.
As I have encountered and solved various difficulties, it seems appropriate to both share the scripts and explain them.
The explanation of them and my process can be found in a YouTube playlist here: [My Video Processing Process](https://www.youtube.com/playlist?list=PLTEuX1zSLveY).

Software used:
- MakeMKV
	- https://www.makemkv.com/
- FFmpeg
	- https://ffmpeg.org/
	- https://github.com/BtbN/FFmpeg-Builds/releases
- SVT-AV1-HDR
	- https://github.com/juliobbv-p/svt-av1-hdr
	- https://github.com/QuickFatHedgehog/FFmpeg-Builds-SVT-AV1-HDR/releases
- video-compare
	- https://github.com/pixop/video-compare
- MKVToolNix
	- https://mkvtoolnix.download/
- Subtitle Edit
	- https://www.nikse.dk/subtitleedit
	- https://github.com/SubtitleEdit/subtitleedit/releases?page=2#release-4.0.16
